# ing-analytics
Build for CSV viewer from ING, simple offline, and easy to use.


# How to use

1. Log into ING bank
2. Pick your account you want to view transcations for.
3. Export CSV for the timerange you want to view, supports multi-year views.
4. Open the HTML File in your browser of choice
5. Click Choose CSV file.
6. Upload
7. Done :D
